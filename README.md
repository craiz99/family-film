# family-film

A cozy, cartoon-style animated **Movie Night** scene featuring a suave fox, an excited purple bat, and a clumsy skunk with a bucket of popcorn on a living room couch.

## Features

- **Self-contained**: Single `index.html` with responsive SVG artwork, CSS keyframe animations, and vanilla JavaScript.
- **Vibrant Living Room**: Plush couch, warm rug, movie snacks, and shifting TV screen glow.
- **Expressive Characters**:
  - **Fox**: Sleek, confident, winking with a swaying bushy tail.
  - **Purple Bat**: Playful, wide-eyed, fluttering and looping around the couch.
  - **Skunk**: Clumsily juggling a striped popcorn bucket with bouncing stray kernels.
- **Interactive Speech Bubbles**: Personality-driven dialogue timeline with click-to-advance and replay controls.

## Usage

Open `index.html` directly in any modern web browser.
